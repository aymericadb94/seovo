7. Optimisations recommandées

Optimisation A — Downgrade Opus → Sonnet (impact : −24%)

L'intent analysis et le cocoon positioning sont des analyses structurées avec output JSON prédéterminé. Sonnet 4 est parfaitement capable de les exécuter.

ÉtapeAvant (Opus)Après (Sonnet)Économie
Intent analysis$0.131$0.027−$0.104
Cocoon positioning$0.252$0.052−$0.200
Total économisé−$0.304/gen

Optimisation B — Fusionner audit + contrôle final (impact : −11%)

Ces deux étapes re-traitent le HTML complet avec un objectif similaire (détecter les défauts, corriger). Fusionner en une seule étape "Quality Gate" élimine un appel de ~$0.14.

Optimisation C — Fusionner enrichissement + valeur ajoutée (impact : −10%)

Même pattern : deux passes séparées sur le même HTML. Fusionner en une étape "Content Improvement" unique.

Optimisation D — Cache par keyword (impact variable)

Les étapes 0-5 (pré-génération) produisent le même résultat pour le même keyword + même site. Cache Redis/Supabase avec TTL 7 jours. Économie estimée : ~$0.03/gen en moyenne (15-25% cache hit).

Optimisation E — Truncate HTML dans les post-steps

Réduire le contenu injecté de 12-14K chars à 8K chars et envoyer un résumé structuré plutôt que le HTML brut. Réduction input de ~30%.
